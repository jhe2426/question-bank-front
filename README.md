# ADsp QuestionBank React Project <br/>
사용자의 기억력 및 집중력 향상을 위한 검사 및 기록 관리 웹 서비스 <br/>

## 피그마 디자인
[피그마 디자인 링크](figma.com/design/qOsVA081AatRnNWWH9kCaa/문제은행?node-id=0-1&m=dev) <br/>

## 개발 기간
* 2025.12.01 ~ 2026.04.12(약 5개월) <br/>

## 시연 영상
[시연 영상 링크](https://youtu.be/G0EVMpZNwKE) <br/>

## 주요 기능
- 회원가입, 로그인
- 단원, 챕터, 난이도 선택 기반 시험 생성
- 문제 풀이 및 답안 선택 기능
- 제한 시간 기반 자동 제출
- 채점 결과 확인 및 시험 이력 조회
- 오답 문제 확인 및 단원별 성적 확인
- 비밀번호 변경 기능 <br/>
